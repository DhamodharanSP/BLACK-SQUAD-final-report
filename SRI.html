Detection Modules

Seven AI Microservices

Each module runs as an independent Python microservice communicating via REST APIs. Simultaneous parallel execution on GPU-enabled hardware.

👤
Face Recognition
MTCNN + InceptionResNetV1 on VGGFace2. 512-dim embeddings, L2 normalization, triplet loss. Cosine similarity threshold 0.8. Privacy-preserving anonymization for non-targets.
98%
recognition accuracy
🔫
Weapon Detection
Custom YOLOv8 trained on 10,000 annotated images. Detects firearms, knives across 70 epochs. Confidence threshold 0.7. Transfer learning + augmentation.
92.8%
mAP@0.5 score
🚨
Behavior Anomaly
YOLOv8 + OpenCV pose estimation + LSTM rule-based temporal reasoning. Detects violence, kidnapping, loitering. 3,500 labeled frames. F1: 89.7%, precision 91.3%.
89.7
F1 score
👥
Crowd Congestion
YOLOv8 person detection + DBSCAN centroid clustering. 5-stage pipeline: detection → centroid extraction → clustering → classification → alerts.
92.4%
classification accuracy
⏱
Temporal Anomaly
LSTM-based temporal analysis for fire, accident, and crime sequences. Sliding time-window motion intensity assessment. Anomaly-driven segmentation removes redundant frames.
LSTM
temporal model
🤖
AI Agent System
Autonomous LangChain agent dispatches prioritized alerts via TTS, mobile API, notification service. LLM generates structured incident reports. Adaptive feedback loop retrains models.
LLM
langchain powered
📊
Threat Fusion Engine
Decision fusion layer: ThreatScore = w₁F + w₂W + w₃B + w₄C. Empirically weighted per environment. Eliminates false positives through multi-modal cross-validation.
4-mod
fusion scoring
